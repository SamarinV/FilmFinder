# FilmFinder

Каталог фильмов на Next.js, React, TypeScript, SCSS и Tailwind CSS. Данные и изображения поступают из TMDB. Доступны подборки, поиск с подгрузкой и страницы фильмов.

## Запуск

Требуется Node.js 24.x и токен доступа TMDB. Версия закреплена в `package.json` и `.nvmrc`.

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env.local`.
3. Укажите `TMDB_TOKEN` — токен API Read Access Token из настроек своего аккаунта TMDB.
4. Запустите `npm run dev` и откройте http://localhost:3000.

Сервер использует `TMDB_API_URL` (по умолчанию в примере https://api.themoviedb.org/3). Для существующих окружений поддерживается `NEXT_PUBLIC_API_URL`; новая серверная переменная имеет приоритет. Не задавайте разные адреса в `.env` и `.env.local` случайно.

## Проверки

- `npm run lint` — ESLint, правила Next.js и TypeScript.
- `npm run format` — единое форматирование JSX/TSX, CSS/SCSS и конфигураций через Prettier.
- `npm run format:check` — проверка форматирования без изменения файлов.
- `npm run typecheck` — TypeScript (после первой сборки Next.js).
- `npm test` — проверки URL, входных параметров и ошибок API, без обращения к TMDB.
- `npm run build` — production-сборка.
- `npm start` — запуск собранного приложения.

Подборки и данные фильмов обновляются с периодом в час. Для внешних запросов установлен таймаут 10 секунд. Поиск ограничен 500 страницами; ошибки не запускают бесконечные повторы, пользователь может повторить загрузку вручную.

На страницах фильмов трейлеры и тизеры берутся из TMDB вместе с подробностями фильма. Приоритет — русский язык, полноценный трейлер, официальная публикация; если русского ролика нет, используется английский. Поддерживаются плееры YouTube и Vimeo. Плеер подключается только после нажатия кнопки, закрывается крестиком, Escape или нажатием на фон. Если подходящего видео нет, кнопка скрыта. TMDB предоставляет ссылки на ролики, поэтому доступность воспроизведения из РФ определяется видеоплощадкой и сетью пользователя.

## Деплой на Vercel

В настройках проекта откройте Settings → Build and Deployment → Node.js Version и выберите `24.x`. Версия также закреплена через `engines.node` в `package.json`. После изменения настроек запустите новый деплой.

В Environment Variables должны быть заданы `TMDB_TOKEN` и `TMDB_API_URL` (либо совместимая переменная `NEXT_PUBLIC_API_URL`). Локальные `.env`-файлы в Git не отправляются.

Для основного сайта выберите окружение Production; для тестовых деплоев — Preview. Значение `TMDB_API_URL`: `https://api.themoviedb.org/3`. В `TMDB_TOKEN` укажите API Read Access Token без префикса `Bearer`. После изменения переменных нужен новый деплой: уже запущенный деплой не получит их автоматически.

Если API возвращает 401, проверьте и токен, и адрес: старый URL Кинопоиска не принимает токен TMDB. Переменная `TMDB_API_URL` имеет приоритет над `NEXT_PUBLIC_API_URL`. Redeploy пересобирает выбранный коммит: чтобы применить исправления кода, сначала закоммитьте их и отправьте в ветку деплоя.

Главная загружает каталог при запросе страницы, а не при сборке; ответы TMDB по-прежнему кешируются на час. Это позволяет собрать приложение при недоступном API, но для работы каталога в запущенном приложении переменные обязательны.

## Секреты

Файлы `.env` и `.env.local` игнорируются Git, пример содержит только пустой токен. Ранее сохранённый в Git токен необходимо отозвать в TMDB и заменить локально и в настройках хостинга. Исключение файла из отслеживания не удаляет его из старых коммитов. Переписывание общей истории Git требует отдельного согласования с участниками проекта.

## Ручная проверка

Проверьте главную, поиск с кириллицей и символом `&`, пустую выдачу, повтор после ошибки и переход между разными запросами. На странице фильма проверьте неизвестный ID, отсутствие постера и похожие фильмы. Проверьте ширины 320, 375, 768 и 1280 px, управление клавиатурой и видимость фокуса.
